# T10 — Real dashboard home (pipeline summary)

## Goal
Replace the placeholder dashboard (sign-in demo + `privateData` echo) with a
real operations home: pipeline summary built from live queries — open leads
count, active jobs, outstanding invoice balances, recent history. The ASCII
landing at `apps/web/src/app/page.tsx` stays as-is in this task (its
redesign is a design call for Johnny, not a worker decision).

## Dependencies
T1. Read-only: composes `listLeads`, `listJobs`, `invoiceBalance` /
`jobFinancials`, `history`. Can build in parallel with T5–T9 (same query
contracts, different files).

## Context
- Current dashboard: `apps/web/src/app/dashboard/page.tsx` (Clerk
  `Authenticated`/`Unauthenticated` pattern + `useQuery(api.privateData.get)`).
- Keep the auth gating pattern; add the summary cards inside
  `<Authenticated>`.
- If a query needed for a card doesn't exist in `backend.ts`, OMIT the card
  and note it in the PR body — do not add backend functions in a UI task.
