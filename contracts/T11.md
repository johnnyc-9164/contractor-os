# T11 — PWA verification (installable + offline)

## Goal
Prove the PWA story the scaffold claims: the app is installable and serves
a working offline fallback. Fix whatever is broken in `pwa.config.ts`,
`manifest.ts`, `public/sw.js`, or `pwa-registration.tsx` — no rewrites of
the PWA approach, just make the configured one actually work.

## Dependencies
T12 (needs a real preview URL — service workers require https / a
deployed origin; localhost exceptions don't prove installability).

## Context
- Graft hubs: `withPwa` (`apps/web/pwa.config.ts`, wraps next config).
- Files: `apps/web/src/app/manifest.ts`, `apps/web/public/sw.js`,
  `apps/web/src/components/pwa-registration.tsx`,
  `apps/web/src/app/layout.tsx` (registration wiring — check it).
- `cd apps/web && pnpm run generate-pwa-assets` exists for icon assets.

## Files (8 max)
1. `apps/web/pwa.config.ts` — fix config gaps only if proven broken
2. `apps/web/src/app/manifest.ts` — ensure required manifest fields
   (name, icons incl. 192/512, start_url, display, theme/background color)
3. `apps/web/public/sw.js` — fix offline fallback if broken
4. `apps/web/src/components/pwa-registration.tsx` — fix registration if broken
5. `apps/web/src/app/layout.tsx` — touch only if registration wiring is missing
6. PWA icons — regenerate via `generate-pwa-assets` only if icons are
   missing/invalid
7. (optional) offline fallback page/route if `sw.js` references one that
   doesn't exist
8. Nothing else

## Verification (5 max)
1. `pnpm --filter web build` — exit 0
2. Against the preview deployment: manifest fetches with HTTP 200 and
   contains icons 192 + 512, `start_url`, `display`
3. Against the preview deployment: service worker registers (document the
   exact browser check used)
4. Against the preview deployment: with network disabled, the app serves
   the offline fallback instead of a browser error page (document steps)
5. `pnpm exec biome check` on touched files — exit 0

## Acceptance criteria
- Installability criteria met on the preview URL (manifest + SW + icons).
- Offline fallback proven with network disabled, steps recorded.
- All evidence (URLs, commands, observed behavior) recorded on issue #3.

## Out of scope
- Push notifications. Background sync. App-store packaging.
