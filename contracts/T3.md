# T3 — Test harness (vitest) + CI workflow

## Goal
`pnpm test` exists and passes, and every push gets typecheck + lint + test +
build on CI. Closes the "no test script" accepted gap (issue #4 asks for
automated coverage with the first feature — this task builds the harness and
lands the first tests; product tasks add feature tests on top).

## Dependencies
None. (Wave 1 — parallel with T1, T2, T12. New files only; do not edit
product code to make tests pass.)

## Files (8 max)
1. `package.json` — add `"test": "vitest run"` (and `test:watch` if free)
2. `vitest.config.ts` — root config (node environment; include
   `packages/*/src/**/*.test.ts` and `apps/web/src/**/*.test.ts`)
3. `.github/workflows/ci.yml` — new: on push/PR, `pnpm install
   --frozen-lockfile`, `pnpm check-types`, `pnpm exec biome check .`,
   `pnpm test`, `pnpm build`
4. `packages/ui/src/lib/utils.test.ts` — first real tests (pure `cn`/utils)
5. `packages/backend/convex/lib/validators.test.ts` — new: unit tests for
   the pure validators re-exported from `@johnnyc2026/contractor-os-core`
   (do not test Convex runtime behavior here — that needs a deployment)
6. Any `vitest`/`@vitest/*` devDependency additions via the catalog
   (`pnpm-workspace.yaml` catalog, matching repo convention)
7. (optional) `apps/web/src/lib/*.test.ts` — only if a pure, testable unit
   exists; no component tests in this task
8. (optional) test setup file if vitest needs one

## Verification (5 max)
1. `pnpm install --frozen-lockfile` — exit 0
2. `pnpm test` — exit 0, and the output shows a nonzero test count (a
   passing suite with zero tests is a failure — assert the count)
3. `pnpm check-types` — exit 0
4. `pnpm exec biome check .` — exit 0 on the new files
5. `git status --short` — new files only under the paths above; no product
   file modified except `package.json` scripts and the catalog

## Acceptance criteria
- `pnpm test` runs a real suite (≥10 assertions) and passes.
- CI workflow exists and its steps mirror the local verification commands.
- No test mocks the thing it is supposed to verify; no skipped tests
  without a named reason in a code comment.

## Out of scope
- Feature tests for T5–T10 (those tasks own them). Convex integration
  tests against a live deployment (needs T12/T13). Playwright/e2e.
