Close issue #3 with runtime proof: on a Vercel preview deployment (never
production), demonstrate Clerk sign-in, a Convex function round-trip, and
PWA offline behavior. Record the exact procedure + command outputs on the
issue. CONFIGURED is not VERIFIED — this task is the verification.

## Dependencies

round-trip should hit the unified backend).

## Context
- What "configured" means today (from the audit): Clerk keys wired via
  Varlock env schema, Convex project linked, PWA config present — none of
  it proven running.
- Non-production credentials and data ONLY. If a step needs a secret the
  worker doesn't have, mark that step BLOCKED and say exactly what Johnny
  must supply — do not work around it.

## Files (3 max — this task is mostly procedure, not code)
1. Issue #3 comment — the evidence log (procedure + outputs)
2. `apps/web/.env.schema` — touch ONLY if a variable the preview needs is
   missing from the schema (then run `pnpm run env:generate`)

   keeping (short: URL pattern, what to click, what to expect)

## Verification (5 max — each is a proof, not a command)
1. Clerk: sign in on the preview URL with a non-production identity;
   record the signed-in state (screenshot or DOM evidence, no credential
   values)
2. Convex: trigger a real query round-trip in the preview (e.g. the
   dashboard summary or `componentInfo`); record request → response
3. PWA: disable network on the preview URL; record the offline fallback
   serving (may duplicate T11's evidence — reference it, don't redo it)
4. `vercel inspect <preview-url>` — deployment healthy at verification time
5. No production data touched, no production deployment triggered
   (state this explicitly on the issue)

## Acceptance criteria
- Issue #3 contains the full procedure and outputs, sufficient for a
  stranger to repeat the verification.
- All three integrations proven WORKING in preview, or the failing one is
  marked BLOCKED with the exact missing input named.
- Zero secrets in the issue, the repo, or the PR.

## Out of scope
- Fixing what the verification finds broken (file a new issue per
  finding, don't scope-creep this task).
- Load testing. E2E suites (that's post-production hardening).
