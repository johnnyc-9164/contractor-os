# T9 — CMS site management UI

## Goal
A working Sites section on the `@johnnyc2026/cms` component via the
`packages/backend/convex/cms.ts` facade: list sites, view a site, create a
site, update a site (with optimistic-concurrency revision handling).
Wired to `listSites`, `getSite`, `createSite`, `updateSite`.

## Dependencies
T1 (facade deployed). Note T4 may tighten the facade's authz — build
against the facade's function signatures, not its internals.

## Context
- `cms.ts` facade args mirror the component validators; `updateSite`
  requires `expectedRevision` and throws on conflict — the UI must surface
  revision conflicts gracefully (refetch + retry prompt, not a crash).
- `createSite` takes `idempotencyKey` — generate one per form submission
  (e.g. `crypto.randomUUID()`) so double-submits don't duplicate.
- Same app/auth/UI conventions as T5–T8.

## Files (8 max)
1. `apps/web/src/app/sites/page.tsx` — new: site list (`listSites`,
   paginated)
2. `apps/web/src/app/sites/new/page.tsx` — new: create-site form
3. `apps/web/src/app/sites/[identifier]/page.tsx` — new: site detail
   (`getSite`) + edit form (`updateSite`)
4. `apps/web/src/components/sites/site-form.tsx` — new: shared create/edit
   form with revision handling
5. `apps/web/src/components/sites/revision-conflict.tsx` — new: conflict
   notice + refetch/retry UX
6. (optional) nav link addition
7. (optional) colocated loading/empty states
8. Nothing else

## Verification (5 max)
1. `pnpm check-types` — exit 0
2. `pnpm exec biome check apps/web/src/app/sites apps/web/src/components/sites` — exit 0
3. `pnpm --filter web build` — exit 0
4. `pnpm test` — exit 0
5. Self-review: `updateSite` always sends the freshest `expectedRevision`;
   `createSite` always sends an `idempotencyKey`

## Acceptance criteria
- Full site CRUD against the real CMS component through the facade.
- Revision conflict produces a recoverable UX, not an error boundary.
- Double-submit of the create form creates exactly one site.

## Out of scope
- CMS schema design (properties/relations shapes are the component's
  domain). Public site rendering.
